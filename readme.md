# Hello World Project

Yeh meri internship ke pehle phase (**Fundamentals and Setup**) ka project hai. Iska maksad yeh check karna hai ki mera development environment (VS Code, Git, GitHub) sahi se set up ho gaya hai.

## Project Description

Ek simple "Hello World" program jo screen par message print karta hai. Isse yeh confirm hota hai ki:

- Code editor aur language sahi se install hui hai
- Git aur GitHub sahi se kaam kar rahe hain
- Main code likh, run aur push kar sakta/sakti hoon

## Tools Used

- **VS Code** - code editor
- **Git** - version control
- **GitHub** - code hosting aur collaboration
- **Python** - programming language (apne role ke hisaab se badal sakte hain)

## Project Structure

```
internship/
├── hello.py      # Main program file
└── README.md     # Project ki jaankari
```

## Setup aur Run Kaise Karein

1. Repository clone karein:
   ```
   git clone https://github.com/aapka-username/hello-world.git
   ```
2. Project folder mein jayein:
   ```
   cd hello-world
   ```
3. Program run karein:
   ```
   python hello.py
   ```

## Expected Output

```
Hello, World!
```

## Git Commands Jo Maine Use Kiye

```
git add .
git commit -m "Add Hello World"
git push
```
